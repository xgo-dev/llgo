#
# Scope: every [go] net line the probes print except the heap marks
# ([go] wifi heap ... lines carry IDF-heap byte counts that legitimately

# the ip= figures are the emulator's fixed station address). The two
# "in <ms>" timings have measured 0 ms in every recorded run (the NAT

# slice), so they are part of the golden; if a run ever reports non-zero
# there, treat the run, not the golden, as suspect before changing anything.
#

# grep -v 'heap ' and byte-diff against this file (comments excluded; both

# udp probe in main, so its lines follow the udp section in the log.

# section, reconnProbe lines only at the end of the reconn section; every

# the acceptance contract.
